# Factor and Alternative-Data Research

Core factors are evaluated independently for Pearson IC, Rank IC, ICIR and temporal stability; quantile portfolios test monotonicity, decay and turnover/cost sensitivity. Exposure and correlation diagnostics identify market-cap/industry dependence and redundant factors. Incremental contribution is assessed separately from standalone predictiveness.

Text research uses a unified financial-event representation rather than a sentiment scalar alone. Event type, entity/scope, direction, importance, novelty, uncertainty, horizon, confidence, source, publish time and ingest time are retained. News, announcements and forums share the same research contract.

Coverage, missingness, latency, PIT violations, source reliability and cross-source conflict are evaluated before signal testing. LLM output is compared with lexical/traditional baselines to distinguish new information from re-encoding.

Text/event output stays `research_only` unless independent, stable OOS evidence passes the common gate. The current default alternative-signal production weight remains zero; a working data path is not evidence of alpha.
