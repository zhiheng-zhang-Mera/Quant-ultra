## 1. 引擎结构评估

**架构**：11 阶段可审计流水线（数据底座 → 切片 → PIT 特征/另类信号 → 标签 → ML → 凸优化 → FSM 回测 →
审计/压力 → 对账 → CIO 治理 → 投顾）+ 自适应多因子周轮动引擎（`Main/weekly_rotation.py`）。

**结构检查结论**（R1–R7 实测）：

| 维度 | 结果 |
|---|---|
| 模块健康 | 106/106 流水线模块 import 通过；6/6 CLI 入口 import 通过；`compileall` 全绿（语法级） |
| 账务自洽 | 净值复利、无杠杆敞口界、无执行日漂移恒等式**精确成立**（0 违规）；止损成本/换手语义已注释 |
| 防泄漏 | 研究证据门（OOS≥6%、夏普≥0.9、回撤≤10%、卡玛≥1.0、DSR 多重检验 + num_trials 注册）；暖启动折线；PIT 全池 |
| 治理 | 失败关闭（HOLD_FOR_REVIEW / OBSERVATION_ONLY）、参数 allowlist + 人工审批、checksum 防篡改 |
| 已知问题修复 | 事件冲击风险处置被再平衡覆盖（R1 缺陷修复）；报告"第三视角审查"自相矛盾文本（R2 修复）；`rank_candidates`/`weekly_rotation` 死代码（R1/R2 清除） |
| 性能 | per-day 标量访问向量化：421 只回测 ~40-60s → **9.9s（4-5×）**，字节一致（R6） |
