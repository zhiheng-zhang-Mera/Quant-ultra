## 3. 自适应模型发现的缺陷与修正

### 3.1 ML 熊市否决是二元硬开关（已修正）
原实现：`ml_res.regime == "BEAR"` 即强制 0 仓。logit 在 2018/2021-2022 概率约 0.6（判牛），
而 2025-2026 有 76% 交易日判熊 → 全窗口约一半时间空仓，既没躲过 2018/2021-2022 慢熊，又错过反弹。
修正：连续概率敞口覆盖 `exposure = ml_bear_floor + alpha * (regime_exposure - ml_bear_floor)`，
`alpha = clip((P_up - ml_bear_low)/(ml_bull_high - ml_bear_low), 0, 1)`，低信心时降到防御底线 0.30。

### 3.2 回撤守卫被再平衡绕过（已修正）
原实现只在当日事后清零权重，下一次再平衡按 regime 目标重建满仓 → 砍仓→回补→再砍的放大循环，
实测启用后回撤从 -25% 恶化至 -31%。修正为状态机：净值回撤达 `drawdown_guard` 后锁仓至
`dd_guard_exposure`（0.35），目标权重尊重锁仓态，基准收复趋势均线后释放。

### 3.3 事件冲击闩锁再入场太慢（已修正）
原闩锁要求基准收复 20 日均线才解除，V 型反弹被错过。新增 `event_shock_recovery_ma=5`，5 日均线快速释放。

### 3.4 BULL 顶部误判（已修正）
BULL 判定新增 20 日动量确认（`mom20 > 0`），修复 2021 年 12 月式“价格在均线上但动能衰竭”的顶部误判。

### 3.5 生产参数缺陷（已修正）
- `bear_exposure=1.0` 使 MA 熊市判定完全不降仓（2018-03 标 BEAR 仍 100% 仓位），防守完全依赖失效的 ML；
- `hold_persistent=True` 死扛滑出前 N 的旧标的；
- `vol_target=0.15, vol_scale_floor=0.6` 只削收益不降回撤（消融：关闭后年化 +2.6pp、季度胜率 +2.4pp）；
- `defensive_core_bull_momentum=False` 使牛市也压制动量，2019Q1 跑输等权基准 27pp；
- `max_annual_vol=0.75` 放行宁德时代/纳指 ETF 等暴雷成长股。

## 4. 系统性消融与网格验证（约 90 组）

所有组合均在 2016-01 ~ 2026-08、57 只（或 40 只高股息）标的、纯多头、无杠杆、收盘信号→次日开盘执行的
同一引擎下验证，logit 按 750 日滚动窗口 walk-forward 拟合，无未来函数。

第三轮补充验证（2026-08-08）：

1. **指数对冲（short 510300）否决**：全对冲使最大回撤恶化至 -42.8%、夏普 0.61（多空错配+借券成本，
   与 git 历史中“market-neutral hedge not beneficial”结论一致），且与生产门槛“融资/杠杆绝对禁用”冲突。

3. csi_div_vt22 回撤结构：仅 2016、2020Q1、2020H2 三段 ≤126 日；2018-2020（466日）、2021-2023（378日）、

## 5. 不可兼得的证据

1. 等权基准自身（57 只标的池）2018 与 2021-2023 的“峰值→新高”恢复期分别约 250 与 600+ 交易日；
   沪深300 在 2021-02 峰值后约 900+ 交易日才创新高。长多策略净值峰值与市场顶部同步时，
   无法在“峰值起 126 个交易日内创新高”的口径下快于市场自身修复。
2. 2021-09-23 策略峰值恰在市场顶部：修正后的高股息书持有银行/能源/煤炭（Oct 2021 - Feb 2022 正确），
   但 Nov-Dec 2021 动量票（白酒/纳指）与 2022H2 能源回落仍使净值 -17.9%，恢复需 378 交易日。
3. 防御降仓与季度跑赢基准存在结构性冲突：任何把 2018/2021-2023 回撤压到 -10% 以内的配置，
   2019/2020/2024 大牛季度都会阶段性与基准拉开（高股息池季度超等权胜率仅 44.2%）。
4. 卡玛≥1.2 要求（年化/最大回撤）≥1.2：前沿上（年化, 最大回撤）组合为
   (13.5%, -20.0%)、(14.4%, -17.9%)、(12.2%, -14.2%)、(10.9%, -14.3%)、(5.2%, -9.7%)，卡玛最高 0.86；
   纯多头、无杠杆、无做空工具（A 股散户无法融券做空 510300）约束下无解。

## 7. 结论

自适应调整代码模型已按 3.1-3.5 修正并通过回归测试（tests/test_improvements.py 新增
`test_ml_bear_override_is_continuous_not_binary`、`test_drawdown_guard_targets_respect_latch_exposure`）。
修正后三项目标维度达标（夏普、季度超等权、季度超沪深300），年化收益从 8.6% 提升至 13.5%，
OOS 更稳健。卡玛≥1.2 与回撤修复≤6个月在纯多头、无杠杆、无对冲工具、2016-2026 十年窗口下
经约 90 组参数/机制/标的池组合验证仍不可兼得，根因是 A 股长熊中市场自身恢复周期即超过目标口径，
且防御降仓与季度跑赢基准存在结构性冲突。报告如实披露差距，不做虚标。
