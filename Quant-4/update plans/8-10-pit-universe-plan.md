## 4.2 重要伪影发现（必须记录，防止重蹈）

1. **稀疏股息面板坍缩**：早期"全池"回测（如 balanced 6.34%、safe 7.71%）是在股息面板仅 61 只时跑的——`trailing_dividend_yield` 与 `close` 列对齐后，其余 5400+ 只的 div_yield 为 NaN，z-score 为 NaN → 评分循环跳过 → 候选池实际坍缩为 61 只股息蓝筹。这不是全池成绩，是伪影。
2. 全量股息（5337 只）就位后，所有配置诚实表现收敛到 **~4.0-4.4%**、夏普 0.5-0.6：balanced 4.27%、safe 4.09%（filter fix）、no-div 4.39%。
3. 修复：defensive_filter 的股息合格条件改为严格 `dy > 0`（原中位数逻辑在稠密面板下形同虚设）；safe 转正结论因伪影撤销，生产默认维持 balanced。
4. **教训**：任何"覆盖率增长导致结果显著变化"的中间数字都不可作为结论，必须以 100% 数据闭合后的结果为准。

## 4.3 诚实结论与下一轮改进杠杆

- 幸存者偏差已 100% 清除：真实年化 ~4.3%，低于沪深300（5.3%）与 PIT 等权池（6.6%）；当前策略是"低回撤包装"而非"选择 alpha"；
- 最大短板：**牛市参与不足（BULL +4.4%）+ 换手成本 38%**；
- 下一轮优先实验（每个 ~20 分钟回测）：
  1. `hold_persistent=True` + `persist_rank_floor` 提升 → 直接降换手；
  2. BULL 状态放宽防御过滤、提高动量权重、扩大 top_n（宽度参与）；
  3. 提高 `min_adv`（只做高流动性大中盘，降低小盘噪声与换手）；
  4. 月度再平衡保持，但增加"持仓延续 + 最小调仓阈值"抑制微调。

## 4. 迭代顺序（每轮：回测 → 自检 → 门禁）

1. **数据闭合**：全池日线 ≥95%、退市股 ≥90%、股息覆盖披露；
2. **诚实 PIT 基准回测**：`--pit` 全池，披露 vs 沪深300、季度胜率、幸存者偏差残余（数据缺口）；
3. **低风险优先调参**：在 PIT 池上复跑 balanced/defensive/safe 原型 + 证据门控，选择"回撤更小且年化不降"的配置；保持无杠杆；
4. **工业门禁自检**：88+ 项测试全绿、覆盖率报告、资金敏感性（10万/30万/50万）、OOS 2022+、开源对比排名刷新；
5. **文档交付**：README/计划数字更新、限制披露（退市股结算近似、BSE 排除、股息缺口）。
