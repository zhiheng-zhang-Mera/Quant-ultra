## 2. 逐因子证据（38 只生产池 + 全池复核）

### 2.1 回购/股东增减持（shareholder_actions）——**拒绝**

从东财公告语料（73792 条）标题关键词构建事件面板（90 日滚动净信号：(回购非注销+增持)−减持，
clip/3 归一化，123 个再平衡日，覆盖 60%）：

| 配置 | 全窗口 年化/夏普 | OOS 年化/夏普 |
|---|---|---|
| base | 7.89% / 0.888 | 5.75% / 0.712 |
| w=0.05 / 0.10 / 0.20 | 7.56 / 7.50 / 6.44% | 5.15 / 4.10 / 1.45% |

正权重全部劣于 base（OOS 随权重单调恶化至 1.45%），虽回撤略浅（-13.6% vs -16.1%）——
**拒绝**。

### 2.2 盈利预期修正代理（earnings_guidance：预增/扭亏 vs 预减/首亏）——**拒绝**

38 只蓝筹池业绩预告稀疏（预增 126 / 预减 6），面板覆盖 53%：

| 配置 | 全窗口 年化/夏普 | OOS 年化/夏普 |
|---|---|---|
| w=0.05 / 0.10 / 0.20 | 7.11 / 7.03 / 8.19% | 4.34 / 3.78 / 5.05% |

w=0.20 接近 base 是稀疏信号（多数为 0）几乎不扰动组合所致；OOS 仍全面劣于 base——**拒绝**。
真实分析师一致预期修正需付费源（如实记录）。

### 2.3 拥挤度（amount_share：成交额横截面占比）——**38 只池伪正，全池拒绝**

新因子 `amount_share`/`amount_share_inv` 入 factor_library（正交性 corr -0.04）：

- **38 只生产池**：w=0.05 曾显示全窗口 8.08%/0.917、OOS 6.14%/0.762 优于 base（首个"跑赢"
  因子）——但 w=0.10/0.15 迅速劣化（OOS 3.38%）；
- **全池 PIT 复核（5478 只）**：w=0.04/0.05/0.06 全面更差——全窗口 5.93-6.00% vs 6.54%、
  卡玛 0.50-0.51 vs 0.636、回撤 -11.7~-11.9% vs -10.3%、OOS 7.66-7.95% vs 8.35%。

**38 只池的改善是小池伪象（与 R19.5 早期再入场的生产池演示同性质），全池证据门拒绝。**

### 2.4 现金流质量（ocf_np = 经营现金流/净利润）——**首个通过全部证据门门槛并采纳**

**数据**：东财现金流表（emweb 原始 API 并行抓取，8 线程 + 2015+ 过滤，506/583 只有数据，
~28 分钟），NOTICE_DATE 公告日 PIT 对齐，生产级集成至 `Main/fundamental_factors.py`
（新增 `ocf_np` 字段 + `load_all_fundamentals` 合并 `fundamentals_cashflow.json` 缓存；
顺带修复了基本面缓存缺失导致的静默空转——实测此前 profit/balance 缓存全部缺失）。

**PIT 修复（重要）**：测试发现 `build_fundamental_panels` 的 `reindex` 会**丢弃周末公告日**的
记录（值丢失、下一交易日才本应可见却从未出现）——修复为 union+ffill（周末公告顺延至下一交易
日，PIT 正确）；修复后**重验全部采纳证据**（见下），单书数字下修（原 1.17 卡玛含伪象），
套筒数字基本不变（分散化平滑完整信息冲击）。

**套筒级证据（生产默认层，PIT 修复版，5478 只全池）**：

| 配置 | 年化 | 夏普 | 卡玛 | 回撤 | 月度胜率 | OOS 年化/夏普 |
|---|---|---|---|---|---|---|
| base 套筒 | 6.55% | 1.085 | 0.661 | -9.91% | 60.2% | 8.35% / 1.346 |
| **套筒+ocf_np:0.05** | **8.53%** | **1.356** | **1.228** | **-6.94%** | **64.8%** | **10.07% / 1.582** |

研究门全部检查通过：OOS 年化 10.07% ≥ 6%、OOS 夏普 1.582 ≥ 0.9、回撤 -6.94% ≤ 10%、
**卡玛 1.228 ≥ 1.0（R19.7 首次达标）**、DSR 大 num_trials 下通过（p≪0.05）。

**单书证据（PIT 修复版，全池）**：w=0.05 → 年化 8.73% vs 6.54%（+2.2pp）、夏普 1.283 vs
1.010、卡玛 0.819 vs 0.636（+0.18，未达 1.0）、回撤 -10.65%（≈base）、OOS 9.59%/1.462 vs
8.35%/1.310——显著优于 base 但单书卡玛未达标；**套筒层（生产默认）达标即采纳**。PIT 审计通过
（公告日跳跃、无未来函数）；与 Sloan（1996）应计异常一致（高经营现金流/净利润=低应计=未来
收益更高）。

**采纳决策：`ocf_np:0.05` 进入生产默认**（run_sleeve_portfolio --fundamental-factors 默认含
ocf_np:0.05）；单书可通过 `--fundamental-factors ocf_np:0.05` 手动启用（证据为显著改善但卡玛
未达 1.0，如实披露）。
