# 8-14 离线评估与风险控制修复轮 (Offline Evaluation & Risk-Control Fix Round)

> 数据环境约束：本机缓存仅有 421 只（PIT 下载子集，中小盘为主），无网络、无全池 master list、无股息缓存。
> 因此本轮的"诚实回测"在**同一 421 只缓存池**上进行绝对口径自洽的相对对比，**不能**与 README 中 5475 只全池数字直接比较；
> 任何结论在接入全池数据后需复验（沿用项目证据门控文化）。

## 1. 验收基线（本轮修复前）

- 测试套件：`pytest Quant-4/tests` 实测 **121 passed / 3 failed / 32 errors**；
  - 失败与错误全部为**环境问题**而非代码缺陷：DSH 沙箱把 POSIX `0o700` 目录模式映射为拒绝访问的 DACL，
    导致 `tmp_path` fixture（32 项 error）与 `tempfile.TemporaryDirectory`（2 项 fail）在受限文件系统上不可用。
- 引擎（421 只缓存池，生产参数，10 万元本金、显式费用、整手、无杠杆）：
  **年化 2.29% / 夏普 0.28 / 卡玛 0.14 / 最大回撤 -16.92% / OOS(2022+) 3.75% / 0.40**。

## 2. 本轮修复与新增（全部默认关闭或字节兼容）

### 2.1 测试环境加固（conftest.py + 测试改造）

- `Quant-4/tests/conftest.py`：Windows 下将 pytest 临时目录模式改为宽松模式、`getbasetemp` 不再 `rm_rf`
  既有 basetemp 且使用工作区内根目录、`tempfile.TemporaryDirectory` 清理容错、dead-symlink 扫描容错。
  语义不变（fixture 隔离与顺序不变），CI（`quant4-ci.yml`，windows-latest）不受影响。
- `test_fundamental_factors.py`：2 个用例改用工作区内默认权限临时目录（`tempfile.TemporaryDirectory`
  在受限文件系统上创建即不可写）。
- 结果：**162 passed / 0 failed / 0 errors**（新增 6 个用例后）。

### 2.2 死代码清除（字节兼容，测试已验证）

- `Main/weekly_rotation.py::rank_candidates`：移除从未被使用的 `z_rows` 局部打分块（plan 8-11 已记录：
  `reversal_1d_weight`/`momentum_windows` 不参与实际打分，排名只消费 `composite_factor_scores`）。
  结果不变（`test_*` 全套回归通过）；`reversal_1d_weight` 标注为 legacy no-op。

### 2.3 真实缺陷修复：事件冲击被再平衡覆盖（风险优先序）

- 缺陷：**再平衡日当天，事件冲击触发的风险处置 pending 会被常规再平衡的 pending 无条件覆盖**，
  导致单日暴跌后的次日开盘仍按满仓目标执行，冲击保护在关键时点失效。
- 修复：冲击 pending 标记 `risk_off=True`，再平衡块（含中性/牛市 ETF 持有快捷路径）检测到
  `risk_off_pending` 时保留风险处置、跳过常规覆盖。
- 验证：新测试 `test_event_shock_zscore.py::test_zscore_rule_cuts_exposure_on_relative_crash`
  （暴跌后次日敞口从 0.95 降至 ~0.45，受单日换手上限 50% 约束——诚实的流动性建模）。

### 2.4 新增机制（默认关闭，生产行为字节不变）

| 参数 | 默认 | 说明 |
|---|---|---|
| `rebalance_min_turnover` | 0.0 | 常规再平衡的最小换手门槛：目标与当前持仓偏差过小时保持不动（带内再平衡），降成本/换手；风险态转换（熊/亢奋/冲击/回撤守卫）始终执行；首次建仓不跳过。 |
| `event_shock_zscore` | 0.0 | 稳健事件冲击检测：基准日收益低于其滚动均值 `z` 个标准差时触发风险处置（窗口 60 日）。固定 2.5% 阈值在小盘高波动池上误触发 158 次（实测），z-score 规则随波动自适应，跨池更稳健。与固定阈值可并存（任一触发即处置）。 |

## 3. 离线评估结果（421 只缓存池，生产参数为基线，35+ 配置网格，同一口径）

| 配置 | 年化 | 夏普 | 卡玛 | 回撤 | OOS 年化 | OOS 夏普 | 季度胜率(沪深300) |
|---|---|---|---|---|---|---|---|
| 基线（生产默认） | 2.29% | 0.28 | 0.14 | -16.92% | 3.75% | 0.40 | 62.8% |
| 事件冲击 3.0%（固定） | 2.94% | 0.35 | 0.19 | -15.33% | 5.41% | 0.57 | 62.8% |
| z-score 3.5 | 2.37% | 0.31 | 0.13 | -18.57% | 6.89% | 0.76 | 58.1% |
| **固定 3% + z-score 3.0** | **3.52%** | **0.40** | **0.24** | **-14.74%** | **6.35%** | **0.65** | **65.1%** |

- 关键诊断：421 只池基准（等权）单日跌幅 ≤-2.5% 的冲击日多达 **158 天**（2016 熔断、2018、2020、2024），
  2.5% 固定阈值近乎常开 → 平均总仓位仅 37%，牛市累计收益 -7.0%（小盘动量追高被反复收割）。
  3% 固定阈值 + z-score 3.0 双规则把误触发降到合理水平，全窗口与 OOS 同时改善。
- 研究证据门：以 35 次尝试注册 `num_trials` 后，DSR 多重检验 p 值在该子集上**诚实返回 HOLD_FOR_REVIEW**
  （OOS 夏普 0.65 不足以通过 35 次尝试的惩罚——门禁按设计工作）；全池 OOS 夏普 ~1.07 的口径下可通过。

## 4. 生产默认决策

- **生产默认参数保持字节不变**（`run_weekly_rotation.default_params()`）：上述改进为默认关闭的新机制
