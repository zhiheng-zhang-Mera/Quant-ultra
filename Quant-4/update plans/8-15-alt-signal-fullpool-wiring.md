## 2. 方法：情绪形态 PIT 信号面板（接线验证，非新 alpha）

- 构造**情绪形态**合成面板（与 R4 的动量代理形态刻意不同）：`sent_t = 0.7·event_t + 0.3·sent_{t-1}`，
  `event = sign(1d ret)·clip(|1d ret|/(2·20d vol), 0, 1)` —— 大幅波动事件引发尖峰、随后按记忆衰减
  （均值回复、持续），定性模拟新闻/论坛情绪在价格事件后的动态。
- **PIT 语义**：仅使用 as-of 当日收盘前可得信息；面板行严格对齐引擎再平衡日历
  （`idx % rebalance_days == 0`，2016-01-01 起），每行覆盖全部 5478 个标的
  （治理门：symbol_coverage=1.0、missing_rate=0）。
- **诚实声明**：信号由价格派生（离线唯一可得 PIT 信息），因此任何提升/拖累只证明通路
  （治理、精确 as-of、方向响应、权重敏感度）在全池上行为正确，**不验证真实新闻/论坛情绪的 alpha**。

## 4. 结论（诚实记录）

1. **通路接线在全池上正确**：治理门 PASS（provenance/有限性/有界 [-1,1]/覆盖率 100%/缺失 0%/
   时延 0.5h < 24h/无 fallback），精确 as-of 消费、绝不回填（新增回归测试锁定）。
2. **情绪形态信号全权重负贡献**（年化 5.30-5.40% vs 6.54%，OOS 6.89-7.81% vs 8.35%）——
   与 R4 的"接线验证而非新 alpha"结论一致；且与 R4 动量代理（子集上 OOS 9.96%/0.92 的提升）
   形成对照：动量代理的提升来自它复述了复合因子已含的 mom20（伪信号），而情绪形态是
   真正不同的形态，在全池上没有可开采方向。**反转型 ≈ 中性**（年化/夏普略高但回撤更差、
   卡玛更低），无方向性 alpha。
3. **生产默认保持 `alternative_signal_weight=0`**：真实新闻/论坛语料到位前不启用；
   通路的治理与 PIT 契约已为真实数据就绪（R4 治理门 + 本轮全池治理门均 PASS）。
4. 真实数据全池复验仍受网络/语料约束（外部数据授权与下载能力），如实记录为数据阻塞，
   不是代码缺陷。
